# Figures

Place generated paper figures in this directory. For empirical ML plots, generate
figures from `results/processed/` with reproducible Python scripts under
`scripts/`, and prefer PDF vector outputs for LaTeX inclusion.

Use SVG as an auxiliary artifact only when inspection or SVG-to-PDF conversion
is useful. Use PNG or JPG only for inherently raster content such as qualitative
image grids.

Example LaTeX usage:

```tex
\begin{figure}[t]
    \centering
    \includegraphics[width=0.9\linewidth]{figures/example.pdf}
    \caption{Short descriptive caption.}
    \label{fig:example}
\end{figure}
```
